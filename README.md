# Архитектура

## Часть 1. Проектирование архитектуры («To Be»)

### 1. Определение типа приложения

Spotiby представляет собой Web приложение, включающее:

- **Backend** – Микросервисное API, включающее микросервисы на языках Java и GO для обработки запросов, взаимодействия с базой данных и объектным хранилищем.
- **Frontend** – веб-приложение на React для UI/UX.

### 3. Обоснование выбора технологий

#### Backend:

- **Spring Boot** – наиболее поддерживаемый и оптимизированный веб-фреймворк на Java.
- **FFMPEG** – инструмент для обработки аудио и видео файлов. Поддерживает конвертацию форматов, редактирование, сжатие и извлечение медиа данных.
- **RabbitMQ/Kafka** – брокеры сообщений, обеспечивающие асинхронную передачу данных между приложениями. RabbitMQ подходит для очередей сообщений, а Kafka — для потоковой обработки больших объемов данных в реальном времени..
- **Redis** – быстрое кэширование данных в памяти. Используется для хранения сессий, кэширования запросов и реализации очередей задач.
- **JWT (JSON Web Token)** – cтандарт для безопасного обмена данными, который используется для аутентификации и авторизации в распределенных системах.
- **MiniO** – объектное хранилище для больших файлов (изображений, аудио). Совместимо с Amazon S3 API, обеспечивает высокую производительность и масштабируемость.
- **ElasticSearch** - поисковый движок для индексирования и быстрого поиска данных. Идеален для полнотекстового поиска, аналитики и логирования.
- **Nginx** - веб-сервер и обратный прокси-сервер, используемый для обработки HTTP/HTTPS запросов, балансировки нагрузки, кеширования и управления трафиком между приложениями.
- **Docker** - платформа для создания, развертывания и управления контейнерами. Docker позволяет упаковать приложение и все его зависимости в один контейнер, что обеспечивает его консистентную работу в разных средах.
- **Docker Compose** - инструмент для определения и управления многоконтейнерными приложениями. С помощью Compose можно описать сервисы, сети и тома, необходимые для приложения, в одном YAML файле и легко запускать все компоненты с помощью одной команды.
- **Go (Golang)** - язык программирования, который отличается своей простотой и удобством для разработки многозадачных и высоконагруженных приложений. Часто используется для создания микросервисов, облачных решений.

#### Frontend:

- **React** – гибкий и мощный фреймворк для создания UI/UX.

### 4. Показатели качества

- **Производительность** – асинхронные операции, кэширование, клиентская оптимизация.
- **Масштабируемость** – контейнеризация и адаптация под облачные сервисы.
- **Безопасность** – JWT-аутентификация, защищённые соединения.
- **Надёжность** – логирование и обработка ошибок.

## Часть 3. Сравнение и рефакторинг

### 1. Сравнение «To Be» и «As Is»

- Четкое разделение микросервисов по функциональным задачам.
- Добавлен WEB-Player Microservice для воспроизведения аудио.
- Добавлен Search Microservice для поиска контента.
- Добавлен Playlist Microservice для управления плейлистами.
- Введены новые базы данных и кэши (Search, Playlist, Track Cache).
- Используется Kafka для событийной передачи данных.

### 2. Выявленные отличия

#### Оптимизировано взаимодействие микросервисов:
- Kafka для событийной передачи данных.
- Стандартизация API.
#### Улучшена производительность:
- Кэширование треков, плейлистов и поиска.
- Оптимизированы обращения к базам данных через Redis.

### 3. Пути улучшения архитектуры

- Оптимизация API взаимодействия между backend и frontend.
- Внедрение автоматизированного тестирования и CI/CD.
- Уменьшение связности компонентов backend.
- Использование событийной модели для снижения нагрузки.
- Оптимизация кэширования для ускорения отклика системы.
