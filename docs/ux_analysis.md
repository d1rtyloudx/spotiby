# Оценка и улучшение UX веб-приложения "Spotify"

## 1. Оценка разрабатываемого ПО по атрибутам качества

### 1.1 Распознаваемость соответствия
**Оценка**: Изначально приложение тестировалось через API-запросы в Postman, без графического интерфейса, но функционал четко отражал цель — предоставление доступа к музыкальному стримингу, воспроизведению треков, добавлению треков в библиотеку и созданию персонализированных плейлистов.

### 1.2 Обучаемость
**Оценка**: Без интерфейса взаимодействие осуществлялось через API-документацию в Postman, что требовало технических знаний. После внедрения базового интерфейса основной функционал (поиск, воспроизведение) стал интуитивным, но создание сложных плейлистов и настройка подписки остаются менее очевидными для новичков из-за недостатка подсказок.

### 1.3 Используемость (операбельность)
**Оценка**: На этапе тестирования в Postman функционал был стабилен, но ограничен отсутствием пользовательского интерфейса. С появлением GUI приложение позволяет легко воспроизводить треки, добавлять их в библиотеку или плейлисты и управлять подпиской. Однако процесс создания плейлистов требует оптимизации для более быстрого доступа.

### 1.4 Защита от ошибок пользователя
**Оценка**: На этапе Postman ошибки обрабатывались только на уровне API-ответов, без защиты для конечного пользователя. В базовом интерфейсе отсутствуют механизмы предотвращения случайных действий, таких как удаление плейлиста, дублирование треков или некорректный поиск.

### 1.5 Эстетика GUI
**Оценка**: Изначально интерфейса не существовало, тестирование проводилось через Postman. После внедрения GUI дизайн минималистичен, но цветовая палитра недостаточно контрастна, особенно для кнопок воспроизведения и добавления треков. Элементы управления плейлистами иногда сливаются с фоном.

### 1.6 Доступность
**Оценка**: На этапе API-тестирования приложение эффективно управляло ресурсами, минимизируя нагрузку. С внедрением GUI сохраняется низкая нагрузка на устройство при длительном воспроизведении. Серверы быстро обрабатывают запросы на поиск, добавление треков и обновление плейлистов.

## 2. Пути улучшения UX
- **Улучшение защиты от ошибок**: Добавить уведомления и подтверждения для действий, таких как удаление плейлиста, дублирование треков или изменение настроек подписки.
- **Оптимизация функционала подписки**: Упростить интерфейс управления подпиской, добавив описания преимуществ (оффлайн-воспроизведение, отсутствие рекламы) и интуитивные элементы для перехода на премиум-план.
- **Улучшение воспроизведения треков**: Добавить настройку качества звука в плеере и быстрый доступ к функциям повтора или перемешивания.
- **Упрощение добавления треков и создания плейлистов**: Внедрить drag-and-drop для добавления треков и возможность массового добавления из результатов поиска.
- **Обновление визуального стиля**: Повысить контрастность интерфейса, улучшить читаемость текста и добавить анимации для кнопок воспроизведения, добавления треков и создания плейлистов.

## 3. Внесённые улучшения
- **Подписка**: Добавлен раздел с описанием преимуществ премиум-подписки (оффлайн-доступ, высокое качество звука, отсутствие рекламы). Реализована кнопка для быстрого перехода к оформлению.
- **Воспроизведение треков**: В плеер добавлены настройки качества звука и кнопки для повтора или перемешивания. Реализованы уведомления о недоступности треков в оффлайн-режиме.
- **Добавление треков**: Внедрена функция drag-and-drop для добавления треков в библиотеку или плейлисты. Добавлены предупреждения о дублировании треков.
- **Создание плейлистов**: Упрощен процесс — можно задать название и обложку при создании. Реализована защита от случайного удаления через диалоговое окно.
- **Дизайн**: Обновлена черно-зеленая цветовая схема с повышенной контрастностью. Добавлены анимации для кнопок и читаемые шрифты для треков и плейлистов.

## 4. До и после: визуальное сравнение
**До**: Интерфейса не существовало, функционал тестировался через Postman с использованием API-запросов.  
**После**: Применен единый черно-зеленый стиль. Улучшения:
- **Страница подписки**: Яркие акценты на кнопке оформления и инфографика преимуществ.
- **Плеер**: Крупные анимированные кнопки управления.
- **Плейлисты**: Обложки с рамками, выделенная кнопка добавления треков.
- **Поиск и библиотека**: Читаемые результаты поиска, подсказки для массового добавления треков.
